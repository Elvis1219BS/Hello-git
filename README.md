# GitC - Agent Instructions

## Project Overview

GitC is a simple Git learning and demonstration repository. It contains basic Python scripts for practicing Git version control workflows.

## Project Structure

```
.
├── hellogit.py      # Simple hello world script
├── hellogit2.py     # Second hello world variant
├── calculator.py    # GUI calculator program (tkinter interface)
├── .gitignore       # Git ignore rules (currently empty)
└── README.md        # This file
```

## Running the Scripts

All scripts are standalone Python files that can be executed directly:

```bash
python hellogit.py      # Prints: Hello, GIT!
python hellogit2.py     # Prints: Hello, GIT2
python calculator.py    # Launches GUI calculator with graphical interface
```

## Development Notes

- **Language**: Python (simple scripts, no external dependencies)
- **Git Workflow**: This repository is used for learning and practicing Git operations
- **Code Style**: Simple, straightforward Python for educational purposes

## Common Tasks

- **Adding new scripts**: Create `.py` files following the existing naming convention
- **Git practice**: Use standard Git workflows (commit, push, pull, branching, etc.)
- **Testing**: Scripts are self-contained and can be run directly

## Quick Start for New Features

1. Create a new Python script in the root directory
2. Ensure it has a simple, clear purpose
3. Test by running it directly: `python script_name.py`
4. Commit changes with descriptive messages
